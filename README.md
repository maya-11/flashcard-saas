# AI Flashcard SaaS

Paste in any text and get a deck of study flashcards generated by AI. Users sign in, save decks, and upgrade to a paid plan through Stripe.

Built during the Headstarter Software Engineering Fellowship (2024).

## Tech stack

- **Next.js** (App Router), React, **Material UI**
- **OpenAI API** (`gpt-4o-mini`) for flashcard generation
- **Clerk** authentication, bridged to **Firebase** with custom tokens
- **Cloud Firestore** for saving users' decks
- **Stripe Checkout** and subscriptions

## Features

- **AI generation:** a Next.js API route sends the text to OpenAI and returns structured flashcards
- **Saved decks** per user in Firestore
- **Auth:** sign-in and sign-up pages, route protection with middleware
- **Payments:** Stripe Checkout sessions for the paid plan, a result page after checkout, and a subscription-cancellation route
- Pricing section and flip-card study view

## How it works

```
Browser ─▶ /api/generate ─▶ OpenAI ─▶ flashcards (JSON)
        ─▶ Firestore (save deck under the signed-in user)
        ─▶ /api/checkout_sessions ─▶ Stripe Checkout ─▶ /result
```

## Running locally

Create `.env.local` with:

```
OPENAI_API_KEY=
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=
STRIPE_SECRET_KEY=
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=
```

Then:

```bash
npm install
npm run dev
```
